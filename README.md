# 🛡️Family Shield🛡️

Family Shield — это мобильное приложение для родительского контроля и безопасного управления семейными устройствами, разработанное на кроссплатформенном фреймворке Flutter с использованием сервисов Firebase.

## 🚀 Основные возможности
* Авторизация и профили: Быстрый вход и регистрация по номеру телефона через Firebase Auth.   
* Семейная привязка: Удобное объединение аккаунтов родителей в единую семью с помощью сканирования защищенных QR-кодов (mobile_scanner).   
* Динамический состав семьи: Отображение статуса и ролей родителей (например, Мама, Папа) в реальном времени.
* Система обновлений: Встроенный сервис проверки и скачивания новых версий приложения напрямую из релизов GitHub.

## 🛠️ Технологический стек
* Фреймворк: Flutter (Dart)   
* Бэкенд и база данных: Firebase (Auth, Realtime Database)   
* Сканирование QR: mobile_scanner   
* Сеть и обновления: http, open_filex, package_info_plus

## 🗺️ Дорожная карта проекта (Roadmap)

* **Этап 1: Базовая инфраструктура и авторизация (Завершено)**
  * Настройка проекта на Flutter и подключение Firebase (Auth и Realtime Database).
  * Реализация авторизации по номеру телефона и сохранение профиля родителя с указанием роли (Мама/Папа) в базе данных.
  * Настройка конфигурации приложения и уникального идентификатора пакета (`com.familyshield.family_shield`).

* **Этап 2: Семейная привязка и сканер (Завершено)**
  * Реализация генерации семейного QR-кода главным родителем (`qr_flutter`).
  * Интеграция сканирования QR-кода (`mobile_scanner`) с защитой релизных сборок (правила ProGuard/R8, `multiDexEnabled`).
  * Механизм связывания аккаунтов двух родителей в базе данных (`linkSecondParent`) и динамическое отображение состава семьи на панели управления.

* **Этап 3: Система обновлений (Завершено)**
  * Интеграция проверки версий приложения через GitHub Releases с помощью `package_info_plus` и `http`.
  * Автоматическое скачивание и запуск установки свежего APK-файла через системный установщик (`open_filex`).
  * Кнопка ручной проверки обновлений в интерфейсе панели родителя.

* **Этап 4: Детские устройства и мониторинг (В разработке / Следующие шаги)**
  * Реализация интерфейса и логики для привязки детского телефона (`pairChildDevice`) по QR-коду родителя.
  * Отображение списка подключенных детских устройств, их статуса сети (`isOnline`) и активности на панели управления.
  * Накопление и отображение баллов активности для ребенка.

* **Этап 5: Дополнительный функционал и полировка**
  * Расширение родительского контроля (уведомления, геопозиция или управление приложениями).
  * Оптимизация интерфейса и подготовка к полноценному релизу приложения.
